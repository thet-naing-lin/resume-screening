Prioritization Criteria

| Priority | Criteria | Example |
|----------|----------|---------|
| High | Affects all users, no workaround | Slow initial load |
| Medium | Degrades experience but functional | Missing logout feedback |
| Low | Nice-to-have, not blocking | Theme toggle |

Issue Structure

Each issue follows the same format:
- Problem — What's wrong
- Expected Behavior — What should happen
- Actual Behavior — What currently happens
- Steps to Reproduce — How to trigger it
- Suggested Fix — Proposed solution (optional)

This makes issues actionable for developers and easy to estimate during sprint planning.
